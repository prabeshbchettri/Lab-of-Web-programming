HTML (HyperText Markup Language) and CSS (Cascading Style Sheets) are the core technologies used to build websites.

HTML provides the structure of a webpage using elements like headings, paragraphs, links, and images. CSS enhances the appearance by adding colors, layouts, fonts, and spacing.
